Отправка почты WordPress через сервис рассылки по HTTP API вместо mail().

== Description ==

Плагин перехватывает все письма WordPress (регистрация, сброс пароля,
уведомления плагинов, формы) и отдаёт их сервису рассылки по HTTP API.
Сервис отвечает за очередь с повторами, DKIM, историю отправки и веб-панель.

Особенности:

* вся почта сайта уходит через сервис, менять код темы или плагинов не нужно;
* письмо собирает сам сервис: кодировки, заголовки, вложения, DKIM;
* отправитель — из настроек плагина, из заголовка From или берётся транспортом
  сервиса (письма не падают с «550 Sender address rejected» на SMTP Яндекса);
* режим очереди не заставляет страницу ждать SMTP-сервер;
* запасная отправка штатными средствами WordPress, если сервис недоступен;
* проверка состояния сервиса и тестовое письмо со страницы настроек;
* журнал диагностики: что произошло с каждым письмом, кто ещё перехватывает почту.

== Installation ==

1. Скопировать каталог `mailerservice` в `wp-content/plugins/` или поставить
   загруженный zip через «Плагины → Добавить новый → Загрузить плагин».
2. Включить плагин.
3. Создать проект на стороне сервиса: `php bin/mailer key:create wordpress`.
4. Открыть «Параметры → Сервис рассылки», указать адрес сервиса и API-ключ.
5. Нажать «Проверить» и отправить тестовое письмо.

Пока не заполнены адрес сервиса и ключ, почта уходит как раньше.

== Changelog ==

= 1.0.3 =
* в режиме «сразу» причина от почтового сервера показывается целиком, а не
  «Сервис ответил кодом 502»;
* в журнал попадает идентификатор письма, даже когда отправить его не удалось —
  по нему письмо находится в панели сервиса.

= 1.0.2 =
* настройки «Отправитель» (Email/Имя): адрес, с которого уходят письма;
* если отправитель не задан и в письме нет From — поле from не передаётся,
  отправителя берёт транспорт сервиса (письма не падают с 550 Sender
  address rejected на SMTP Яндекса).

= 1.0.1 =
* журнал диагностики: что происходит с каждым письмом;
* раздел «Диагностика» на странице настроек: окружение, перехватчики почты,
  журнал событий;
* адрес сервиса без протокола теперь дополняется http:// при сохранении.

= 1.0.0 =
* первая версия: перехват wp_mail, страница настроек, проверка сервиса,
  тестовое письмо.
