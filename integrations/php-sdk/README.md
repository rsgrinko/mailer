# Мини-SDK для PHP-проектов

Один файл без зависимостей: `MailerClient.php`. Скопируйте его к себе в проект,
подключите `require` — и письма уходят в сервис рассылки по HTTP API.

Требования: PHP 8.0+. `curl` не обязателен — при его отсутствии клиент ходит потоками.

## Установка

```php
require '/путь/к/MailerClient.php';

use Mailer\Sdk\Client;
use Mailer\Sdk\Mail;
use Mailer\Sdk\MailerException;
```

Ключ проекта выдаётся на стороне сервиса: `php bin/mailer key:create`.

```php
$mailer = new Client(
    'http://mail.internal',   // адрес сервиса
    'mlr_ваш_ключ',           // API-ключ проекта
    15                        // таймаут запроса, секунды (необязательно)
);
```

## Отправка

```php
$result = $mailer->send(
    Mail::to('user@example.com')
        ->subject('Заказ №1024 оформлен')
        ->html('<p>Спасибо за заказ!</p>')
        ->tag('заказы')
);

echo $result['id'];      // идентификатор письма в сервисе
echo $result['status'];  // queued
```

Письмо принимается в очередь и уходит потом, поэтому `send()` возвращается сразу и не
зависит от того, отвечает ли почтовый сервер. Нужен результат отправки здесь и сейчас —
`sendNow()` или `->sync()`.

## Методы клиента

| Метод | Что делает |
|-------|------------|
| `send($mail)` | ставит письмо в очередь |
| `sendNow($mail)` | отправляет сразу и ждёт результата |
| `status($id)` | состояние письма и его история |
| `messages($filters)` | список писем проекта |
| `retry($id)` | вернуть письмо в очередь |
| `cancel($id)` | отменить письмо |
| `templates()` | список шаблонов |
| `suppressions($filters)` | стоп-лист: кому проект больше не пишет |
| `suppress($email, $reason, $note)` | закрыть адрес |
| `unsuppress($email)` | открыть адрес обратно |
| `health()` | состояние сервиса |

## Методы письма

| Метод | Что задаёт |
|-------|-----------|
| `Mail::to($to)` | получатели: строка, «Имя &lt;адрес&gt;» или массив |
| `from($email, $name)` | отправитель |
| `cc($cc)`, `bcc($bcc)` | копии и скрытые копии |
| `replyTo($email)` | адрес для ответа |
| `subject($text)` | тема |
| `text($text)`, `html($html)` | тела письма |
| `template($name, $data)` | письмо по шаблону сервиса |
| `attach($name, $content, $type)` | вложение из данных в памяти |
| `attachFile($path, $name)` | вложение из файла |
| `inlineImage($cid, $path)` | картинка внутри HTML: `<img src="cid:логотип">` |
| `header($name, $value)` | свой заголовок письма |
| `tag($tag)` | метка для поиска в панели |
| `meta($array)` | данные, которые вернутся в вебхуке |
| `transport($name)` | отправить конкретным транспортом |
| `priority($number)` | приоритет в очереди (меньше — раньше) |
| `sendAt($when)` | отложенная отправка: `'2026-01-01 10:00:00'` или `'+2 hours'` |
| `idempotencyKey($key)` | защита от дублей при повторах на своей стороне |
| `sync()` | дождаться отправки |

Имена в `transport()` и `template()` ищутся среди доступных владельцу проекта: свои
плюс общие транспорты. Чужое имя для проекта не существует — ответ будет как на опечатку.

## Ошибки

```php
try {
    $mailer->send(Mail::to('user@example.com')->subject('Привет')->text('Тело'));
} catch (MailerException $e) {
    // $e->getMessage() — что не так
    // $e->getCode()    — код ответа сервиса (401, 422, 429 …)
    // $e->errors       — список ошибок валидации
    // $e->response     — весь ответ сервиса
    error_log('Письмо не ушло: ' . $e->getMessage());
}
```

У `sendNow()` отдельный случай — код `502`: письмо приняли и сохранили, а почтовый сервер
его не взял. В сообщении будет причина от транспорта, а идентификатор письма лежит в
`$e->response['id']` — по нему письмо ищется в панели и повторяется.

## Стоп-лист

Адресам из стоп-листа сервис не пишет: получатель отсеивается на приёме, а если закрыты
все получатели, письмо принимается со статусом `suppressed`.

```php
$mailer->suppress('ivan@example.com', 'unsubscribe', 'нажал «отписаться»');
$mailer->suppressions(['reason' => 'bounce']);
$mailer->unsuppress('ivan@example.com');
```

Причины: `bounce`, `complaint`, `unsubscribe`, `manual`. Ключ закрывает адрес только для
своего проекта; закрытый для всех проектов сразу снимается только в панели.

## Вебхуки

Сервис сообщает о судьбе письма на адрес, заведённый в панели (Вебхуки → Вебхуки проектов).
Готовый приёмник с проверкой подписи и идемпотентностью — `examples/webhook-receiver.php`.

## Примеры

В каталоге `examples/`:

- `basic.php` — простое письмо;
- `template.php` — письмо по шаблону;
- `attachments.php` — вложения и картинка внутри HTML;
- `bulk.php` — рассылка по списку с метками и приоритетом;
- `suppressions.php` — стоп-лист: закрыть адрес, посмотреть список, открыть обратно;
- `webhook-receiver.php` — приёмник вебхуков.

Запускаются с адресом сервиса и ключом в окружении:

```bash
MAILER_API=http://mail.internal MAILER_KEY=mlr_ваш_ключ php examples/basic.php
```
